# 가림 - AI 개인정보 가리개

AI 채팅(ChatGPT, Claude, Gemini 등)에 글을 붙여넣을 때 전화번호, 주민등록번호, 계좌번호 같은 개인정보를 **브라우저 안에서** 기호로 바꿔 보내고, AI 답변에서는 원래 값으로 되돌려 보여주는 크롬 확장 프로그램입니다.

```
붙여넣은 글:   김철수 고객(010-1234-5678, 900101-1234567)의 계약 건 정리해줘
AI로 전송:     [비공개1] 고객([전화1], [주민번호1])의 계약 건 정리해줘
화면의 답변:   김철수 고객님의 계약은 ...   ← 원래 값으로 복원되어 보임
```

## 특징

- **외부 전송 없음**: 모든 처리는 내 브라우저 안에서 끝납니다. 서버도, 분석 도구도 없습니다. 코드를 직접 확인할 수 있습니다.
- **한국형 개인정보 탐지**: 주민등록번호, 휴대폰·일반 전화, 계좌번호, 카드번호(Luhn 검증), 사업자등록번호(검증 숫자 확인), 운전면허번호, 여권번호, 이메일
- **항상 가릴 단어**: 이름, 회사명처럼 형식이 없는 정보는 직접 등록해서 가립니다.
- **같은 값은 같은 기호**: `010-1234-5678`과 `01012345678`은 둘 다 `[전화1]`이 되어 AI가 같은 사람으로 이해합니다.
- **기록은 잠깐만**: 원래 값과 기호의 대응표는 메모리에만 있고 브라우저를 닫으면 지워집니다.

## 지원 사이트

기본: ChatGPT, Claude, Gemini, Perplexity, Microsoft Copilot, DeepSeek, Grok, 뤼튼

그 외 사이트는 확장 프로그램 아이콘을 누르고 **"이 사이트에서도 사용하기"** 를 누르면 추가됩니다. 모든 사이트 접근 권한은 처음부터 요청하지 않고, 사용자가 추가한 사이트에만 권한을 받습니다.

## 설치 (개발자 모드)

1. 이 저장소를 내려받습니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드** 를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 `garim` 폴더를 선택합니다.

## 동작 방식

| 단계 | 하는 일 |
|---|---|
| 가리기 | 입력창에서 붙여넣기(Ctrl+V)를 가로채 개인정보를 기호로 바꾼 뒤 입력창에 넣습니다. |
| 되돌리기 | 화면에 `[전화1]` 같은 기호가 나타나면 원래 값으로 바꿔 보여줍니다. 입력창 안은 바꾸지 않습니다. |
| 변형 대응 | AI가 기호를 `[전화 1]`, `【전화1】`, `전화1`처럼 바꿔 써도 되돌립니다. |

## 한계

- **붙여넣기만 가립니다.** 키보드로 직접 입력한 내용은 아직 가리지 않습니다.
- **탐지는 완벽하지 않습니다.** 이 도구는 보조 수단이며, 민감한 내용은 보내기 전에 직접 확인하세요.
- 파일 첨부(PDF, 엑셀 등)는 처리하지 않습니다.
- AI 사이트의 화면 구조가 바뀌면 일부 동작이 깨질 수 있습니다.
- 데스크톱 앱, 모바일 앱에서는 동작하지 않습니다.

## 개발

```
garim/
├── manifest.json
├── background.js       사용자가 추가한 사이트에 스크립트 등록
├── src/
│   ├── patterns.js     개인정보 탐지 규칙
│   ├── masker.js       가리기/되돌리기 엔진
│   ├── storage.js      설정·대응표 저장
│   └── content.js      AI 사이트에서 실행되는 코드
├── popup/              확장 프로그램 아이콘을 눌렀을 때 뜨는 창
└── test/test.html      엔진과 붙여넣기 동작 테스트
```

테스트는 `test/test.html` 을 로컬 서버로 열면 실행됩니다. Windows에서는 다음 명령으로 서버를 띄울 수 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File test/serve.ps1 -Root . -Port 8765
```

그다음 `http://localhost:8765/test/test.html` 을 열면 결과가 표시됩니다.
